# Ascii–1 매뉴얼

PNG 를 ASCII 아트로 바꾸는 명령형 도구입니다. 소개는 [README](../README.md), 설치 절차는 [INSTALL.md](../INSTALL.md)에 있습니다.

- **개발 중** — 지금 되는 것은 `version` · `help` 와 PNG 읽기 모듈뿐입니다. 변환 명령은 아직 없습니다
- **내 PC 전용** — 네트워크를 쓰지 않고, 파일은 사용자가 지정한 PNG 만 읽습니다

## 명령

| 명령 | 하는 일 |
|---|---|
| `python ascii-1.py version` | 버전 |
| `python ascii-1.py help` | 도움말 |

## 읽을 수 있는 PNG

`ascii1_png.py` 가 표준 라이브러리(`zlib` · `struct`)만으로 읽습니다. 결과는 늘 8 비트 RGB 이고, 투명한 곳은 흰 바탕으로 칩니다.

| 항목 | 지원 |
|---|---|
| 색 유형 | 회색 · RGB · 팔레트 · 회색+알파 · RGBA |
| 비트 깊이 | 1 · 2 · 4 · 8 · 16 (16 비트는 위 바이트만) |
| 줄 필터 · 인터레이스 | 0–4 · Adam7 |
| 투명 | 알파 채널 · 팔레트 투명도 · 회색/RGB 투명색 |
| 한도 | 한 변 4000 픽셀 · 파일 64 MB |
| 읽지 않는 것 | JPEG 를 비롯한 PNG 가 아닌 파일 (확장자가 `.png` 여도 안이 JPEG 이면 `JPEG 로 보입니다` 하고 거부) |

깨진 파일 · 잘린 파일 · 압축 폭탄은 `PngError` 한 줄로 끝납니다. 원본은 어떤 경우에도 바꾸지 않습니다.

## 그림에서 요소 찾기

`ascii1_seg.py` 가 PNG 에서 바탕 · 선 · 점 · 원 외곽(웨이퍼) · 글자를 가릅니다. 아직 글자로 바꾸는 단계는 없습니다. 방법과 잰 값은 저장소의 `docs/plans/ascii-1-design.md` 08 에 있습니다.

| 찾는 것 | 방법 |
|---|---|
| 색 | 바탕과 먼 칸을 색상으로 최대 6 군집(검정 · 회색은 중립 하나) |
| 선 | 한 행(열)의 40% 이상에 걸친 가로선 · 세로선 |
| 마커 | 선에 붙어 있어도 거리 변환으로 뗍니다 (선보다 충분히 굵을 때). 가로 · 세로선이 없는 차트는 곡선의 두께를 직접 재서 가릅니다 |
| 점 | 낱점 면적으로 개수를 추정합니다 — 뭉친 점은 추정치입니다 |
| 웨이퍼 외곽 · 노치 | 정사각에 가까운 둥근 외곽과 안쪽으로 패인 곳 |
| 글자 | 줄을 이룬 작은 덩어리는 읽지 않고 비웁니다 |
| 분석 안 함 | 바탕이 아닌 곳이 절반이 넘는 그림(사진 · 채워진 그림) |

## 글자 아트로 옮기기

`ascii1_render.py` 가 찾은 요소를 글자 격자로 옮깁니다. 아직 명령으로 부르는 길은 없습니다. 격자 줄은 순수 ASCII 이고, 맨 아래 범례(한국어)가 군집마다 어떤 글자를 줬는지 알려 줍니다.

| 요소 | 글자 |
|---|---|
| 점 | 개수 많은 색부터 `o O @` · `x X %` · `* # &` — 왼쪽이 낱점, 가운데가 둘 이상, 오른쪽이 빽빽한 셀 |
| 가로선 · 세로선 | 검정 · 회색은 `-` `\|`, 색 있는 선은 `=` `~` (세로는 `!` `:`), 가로 · 세로가 만나면 `+` |
| 곡선 | `_ - / \ \|` (기울기를 따라). 마커 사이는 마커 중심까지 이어서 끊기지 않게 |
| 웨이퍼 외곽 · 노치 | `.` · 노치는 원의 방향에 따라 `v` `^` `<` `>` |
| 글자 · 숫자 | 읽지 않고 비웁니다 (범례에 몇 곳인지만) |

격자는 열 수(기본 120, 40–300)에 맞춰 만듭니다. 열 수는 그림 전체가 아니라 **그려질 내용의 폭**에 걸리므로 여백에 열을 쓰지 않고, 셀 가로가 1 픽셀보다 좁아지지는 않습니다(웨이퍼 225 픽셀 그림은 최대 약 130 열). 셀 세로를 가로의 2 배로 잡아 원이 둥글어 보입니다. 해상도를 높이려면 열 수를 늘립니다. 점은 추정 개수입니다.

## 개발

| 할 일 | 명령 |
|---|---|
| 테스트 | `python -m unittest discover -s tests` (표준 라이브러리만 — 시험용 PNG 인코더는 `tests/pngenc.py` 에만 있습니다) |
| works 규칙 검사 | 저장소 루트에서 `python tools/works_check.py` |

CI(`.github/workflows/ascii-1.yml`)는 Windows · Ubuntu × Python 3.8 · 최신에서 테스트를 돌립니다. 테스트 그림은 전부 코드로 만든 것입니다.

## 데이터

## 알려진 한계

- 이 문서의 대부분은 설계 단계입니다. 사양 · 출력 모양은 `docs/plans/ascii-1-design.md` 를 보세요
- 요소 찾기는 마커가 선 두께의 2 배 + 2 px 보다 작으면 선과 마커를 못 가르고, 둥근 낱글자(`0`)는 점과 구분이 안 됩니다. 점선은 점으로 셉니다
- 속도: 1000×1000 RGB 를 읽는 데 필터에 따라 0.01–1.4 초 (Linux · Python 3.13 에서 잰 값). Windows · Python 3.8 에서는 더 걸릴 수 있습니다
