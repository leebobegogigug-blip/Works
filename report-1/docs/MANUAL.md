# Report–1 매뉴얼

근거 달린 보고서. 토픽 하나에 메일 · 메신저 · 회의 메모 · 기사 · 엑셀 표를 순서 없이 붙여 넣으면, 사내 LLM 이 양식에 맞춰 두괄식으로 정리하고 줄마다 근거 조각을 붙입니다.
소개는 [README](../README.md), 설치 절차는 [INSTALL.md](../INSTALL.md)에 있습니다.

- **파일 하나** — `report-1.py` 만 있으면 됩니다. 표준 라이브러리만 씁니다
- **근거 없는 사실은 없다** — 사실 · 추론 · 확인 줄에 근거 조각이 없으면 `ERR`, 확정할 수 없습니다. 사람이 고친 줄은 `직접`
- **원문은 메모리에만** — 붙여 넣은 글은 **보관**을 눌러야 저장됩니다. 확정한 보고서는 복사한 글 그대로만
- **내 PC 전용** — `127.0.0.1` 에만 열리고, 밖으로 나가는 통신은 설정한 LLM 주소뿐. 사내 LLM 에는 체크한 조각만 보냅니다

## 설정 (`%LOCALAPPDATA%\report-1\config.json`)

| 키 | 설명 |
|---|---|
| `llm.*` | 사내 LLM — [works LLM 규격](../../docs/SPEC-llm.md) 과 같은 키. 비워 두면 기본 초안(자료를 그대로 묶기)만 |
| `report.forms` | 양식 이름 → 칸 이름 목록 (최대 8칸). 빈 목록 `[]` = 자유 구성 (요약 다음 칸을 LLM 이 정함). ① 노브는 이 순서대로 돕니다 |
| `report.summary` | 맨 위 `요약` 칸 (결론부터 3줄 이내). 기본 `true` |
| `report.budget_chars` | 사내 LLM 에 한 번에 보낼 자료 글자 수 한도 (기본 20,000). 넘으면 보내지 않고 체크를 풀어 줄이라고 알립니다 |
| `theme` | `dark`(기본) · `light` · `system` |
| `company` | 화면 위 `REPORT–1` 옆에 작게 넣는 회사 이름 (24자까지 · 비우면 없음). 저장소에는 넣지 않고 이 PC 설정에만 둡니다 — `--set "company=회사이름"` |
| `port` | 기본 `8775` (대장의 8775–8784 안에서 빈 곳) |
| `idle_exit_min` | 창을 닫고 이만큼(분) 지나면 저절로 꺼짐. `0` 이면 안 꺼짐 (기본 30). 보관 안 한 자료가 있으면 꺼지지 않고 기다립니다 |

전체 기본값은 [`config.example.json`](../config.example.json). 폴더는 `REPORT_HOME` 환경 변수로 바꿀 수 있습니다.

양식 고치기 — 셸마다 따옴표가 달라서 칸은 `;` 로 나눕니다:

```text
python report-1.py --set "report.forms.주간 점검=현황;이슈;다음 주 계획"     더하기 · 바꾸기
python report-1.py --set "report.forms.검토 보고="                          지우기
```

처음 고칠 때 기본 양식 다섯 가지가 `config.json` 으로 옮겨지고, 그 뒤로는 거기 적힌 것만 씁니다 (지운 양식이 되살아나지 않게).

## 쓰는 법

1. **토픽** 을 적습니다 — 보고서 제목이 됩니다
2. 모아 둔 글을 **그냥 붙여 넣습니다** (Ctrl+V). 화면 어디서든 됩니다. 직접 쓴 메모는 붙여 넣는 칸에 적고 Ctrl+Enter
3. 왼쪽에서 빼고 싶은 조각은 체크를 풉니다 (사내 LLM 에도 안 갑니다). 자료째로 빼려면 자료 머리의 체크를, 지우려면 `×` (20초 안에 되돌리기)
4. **① 양식** 을 고르고 **초안 만들기** (Ctrl+Enter)
5. 줄마다 근거 칩을 봅니다. 칩에 올리면 왼쪽의 조각이 켜집니다. 고칠 줄은 눌러서 고치고, 필요 없는 줄은 `×`, 더할 줄은 `+ 줄`
6. **확정** (Ctrl+Shift+Enter) — 도장이 찍히고 보고서 글이 클립보드로 갑니다. 20초 안에는 Ctrl+Z 로 되돌리기
7. 며칠에 걸쳐 모으는 토픽이면 **보관** (Ctrl+S). 나중에 `보관함` 에서 다시 엽니다

`근거 붙이기` 를 켜고 확정하면 줄 끝에 `[1]` 이 붙고, 맨 아래에 `※ 근거` 목록(자료 종류 · 제목 · 조각 앞부분)이 붙습니다.

노브: ① 양식 ② 분량(짧게 · 보통 · 자세히 = 칸마다 3 · 6 · 10줄) ③ 어조(개조식 · 서술식) ④ 독자(팀 내부 · 상사 · 임원) — Alt+1~4, Shift 를 같이 누르면 거꾸로. 양식을 바꾸면 초안을 비웁니다.

창 없이: `python report-1.py --draft 메일.txt 메모.txt --topic "9월 결제 지연" --form "이슈 보고"` (파일 하나 = 자료 하나 · `-` 는 표준 입력 · UTF-8 이 아니면 CP949 로 읽음 · 아무것도 저장하지 않음).

## 자료 → 조각

| 자료 | 알아보는 법 | 조각 |
|---|---|---|
| 메일 | `보낸 사람:` `제목:` `From:` 같은 머리 두 줄 이상 | 문단마다. 제목 줄이 자료 제목. `>` 인용 줄은 건너뜀 |
| 대화 | `[이름] [오후 2:10]` 같은 줄 세 개 이상 | 줄을 묶어 420자 안쪽으로. 첫 말이 자료 제목 |
| 표 | 줄의 60% 이상에 탭 (엑셀에서 복사) | 줄마다 `머리글: 값 · …` |
| 글 · 메모 | 그 밖 | 빈 줄 · 구분선(`-----`)마다. 긴 문단은 문장 → 띄어쓰기 순으로 420자 안쪽으로 |

- 60자보다 짧은 조각(인사 · 머리 한 줄)은 다음 조각과 묶습니다.
- 이미 있는 조각과 같으면(띄어쓰기 · 문장부호 무시) 건너뜁니다 — 답장마다 되풀이되는 본문. 건너뛴 수는 자료 아래에 보입니다.
- 자료 id `a1` · 조각 id `p1` 은 지워도 다시 쓰지 않습니다.
- 한 번에 100,000자 · 토픽 하나에 400,000자 · 조각 3,000개까지.

## 근거 규칙

| 줄 | 뜻 | 근거가 없으면 |
|---|---|---|
| 사실 | 조각에 적힌 것 | `ERR` — 확정 안 됨 |
| `추론` | 조각 여러 개를 이어 LLM 이 내린 판단 ('~로 보임') | `ERR` |
| `확인` | 조각끼리 내용이 다름 — 복사한 글에 `(확인 필요)` | `ERR` |
| `빈칸` | 양식 칸에 필요한데 자료에 없음 — 복사한 글에 `— 자료 없음 (확인 필요)` | (근거가 없는 게 정상) |
| `직접` | 사람이 고치거나 더한 줄 | 확정할 수 있음 |

- 근거 칩은 **체크된 조각만** 인정합니다. 체크를 풀면 그 조각만 근거로 단 줄은 `ERR` 이 됩니다.
- **숫자 검사**: 줄의 숫자가 근거로 단 조각에 없으면 `숫자?` 칩과 물결 밑줄. `1,240` · `1240` · `09` · `9` 는 같은 숫자로 봅니다. 한 자리 정수('3건' 처럼 센 숫자)는 세지 않습니다. 확정은 막지 않습니다 — 확인은 사람이.
- 확정할 때 서버가 근거를 **다시** 판정합니다. 화면이 보낸 상태는 믿지 않습니다.
- LLM 이 글 속에 `[p3]` 처럼 근거를 박아 넣으면 근거 칩으로 옮깁니다.

## 화면

| # | 구역 | 보여 주는 것 |
|---|---|---|
| 01 | **SOURCES** | 토픽 · 붙여 넣는 칸 · 한도 계기판 · 자료 카드(종류 · 제목 · 조각 수 · 글자 수 · 건너뛴 것) · 조각(체크 = 초안 · LLM 에 씀, 눌러서 펼치기) |
| 02 | **DRAFT** | 제목 · 요약 · 양식 칸 · 줄마다 근거 칩 · `ERR` `숫자?` `추론` `확인` `빈칸` `직접` · 노브 값 칩 · 확정 도장 |
| 03 | **DECK** | 노브 네 개 · 근거 붙이기 · 되돌리기 · 보관 · 초안 만들기 · 확정 |
| 04 | **보관함** | 보관한 토픽(열기 · 지우기) · 확정한 보고서(보기 · 복사) |

LED: `보관` 라임 = 보관됨 · 흰색 = 보관 안 한 자료 있음 / `llm` 라임 = 연결됨 · 흰색 = 마지막 요청 실패.

## 디자인

works 공통 규격(원칙 일곱 가지 · 팔레트 · 아이콘)은 [docs/DESIGN.md](../../docs/DESIGN.md) 에 있습니다. Report–1 에서는 이렇게 보입니다.

| # | 원칙 | Report–1 에서 |
|---|---|---|
| 1 | **한 화면 = 한 모드** | 자료와 보고서를 한 화면에, 값은 노브 네 개로 |
| 2 | **색 = 조작** | 노브 ①파랑 ②라임 ③흰색 ④회색 — 보고서 칸 위의 값 칩도 그 색 · LCD 의 양식 이름은 ① 양식의 색 · 한도 계기판은 ② 라임 |
| 3 | **번호 붙은 구역** | `01 SOURCES` · `02 DRAFT` · `03 DECK` · `04 보관함` |
| 4 | **엔지니어링을 숨기지 않기** | 자료 id · 조각 id(`p3`) · 글자 수 · 한도 · 건너뛴 조각 수 · LED `보관` `llm` · 모델 이름 |
| 5 | **즉각 반응** | 붙여 넣으면 결재판이 받아먹고, 근거 칩에 올리면 조각이 켜지고, 확정에 도장 · 되돌리기 초읽기 |
| 6 | **사각 격자** | 점 격자 바탕 · 빗금 붙여 넣는 칸 · 두 자리 번호 |
| 7 | **캐릭터** | 결재판 얼굴 — 붙여 넣으면 뛰어 받고, 초안을 쓰는 동안 생각하고, 확정하면 뛰고, ERR 이면 떤다 |

경고는 빨강 대신 가장 밝은 글자색 칩(`ERR` · `숫자?`)과 물결 밑줄로 합니다.

## 개발

| 할 일 | 명령 |
|---|---|
| UI 수정 | `ui.html` 수정 → `python build.py` (report-1.py 에 내장됨 · `INDEX_HTML` 을 직접 고치지 말 것) |
| 반영 확인 | `python build.py --check` (UI · 폰트 둘 다) |
| 테스트 | `python -m unittest discover -s tests` (표준 라이브러리만 · 가짜 LLM) |
| 브라우저 E2E (선택 · CI 에서는 자동) | `pip install playwright` → `python -m playwright install chromium` → `python tests/e2e_ui.py` |
| 문서 사진 다시 찍기 | `python tests/e2e_ui.py --pages` (`docs/page/` 의 hero · title · err) |
| works 규칙 검사 | 저장소 루트에서 `python tools/works_check.py` ([RULES.md](../../RULES.md)) |

`tests/fake_llm_server.py` 는 OpenAI 호환 가짜 서버입니다 (근거대로 쓰기 · 지어내기 · 없는 숫자 · 글 속 근거 · 코드 울타리 · 엉터리 · 잘린 답 · 500 오류).
테스트는 원문이 **보관 전에는 디스크 어디에도 없는지**, 체크를 푼 조각이 LLM 요청에 없는지, 화면이 위조한 상태를 서버가 다시 판정하는지를 직접 확인합니다.
CI(`.github/workflows/report-1.yml`)는 Windows · Ubuntu × Python 3.8 · 3.13 에서 `build.py --check` 와 단위 테스트를, Ubuntu 에서 브라우저 E2E 를 돌립니다.

`%LOCALAPPDATA%\report-1\` 에 저장합니다. 저장소에는 들어가지 않습니다.

| 파일 | 내용 | 언제 |
|---|---|---|

| `reports\<날짜-시각>.json` | 확정한 보고서 — 제목 · 칸 · 줄 · 근거 id · 복사한 글 (조각 원문은 넣지 않음) | 확정할 때 |

파일이 깨져 있으면 `.broken` 으로 백업하고 새로 시작합니다. 더 새 버전의 Report–1 이 쓴 파일이면 읽기만 합니다 (열어서 고친 뒤 보관하면 새 파일로).

## 알려진 한계

- **인용을 확인하지, 뜻을 확인하지는 않습니다.** 근거 조각을 달고도 내용을 부풀린 줄은 숫자가 아닌 한 잡지 못합니다 — 확정 전에 근거 칩에 올려 한 번씩 보세요
- 한도(`report.budget_chars`)보다 긴 자료는 한 번에 보내지 않습니다. 나눠 보내 합치는 기능은 아직 없습니다 — 체크를 풀어 줄이세요
- 이미지 · 첨부 파일은 읽지 않습니다 (글만). 표는 엑셀에서 복사한 탭 구분만 알아봅니다
- 서식 있는 글(HTML)은 서식 없이 글로만 붙습니다
- 클립보드 복사가 막힌 PC 면 `보관함` 에서 보고서를 열어 직접 복사합니다
