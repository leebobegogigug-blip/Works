# works 디자인

works 앱의 화면 · 문서 규격 **정본**이다 ([RULES.md › W-10](../RULES.md#w-10-디자인은-하나)).
앱 문서는 이 파일을 링크하고, 원칙 · 색 값을 옮겨 적지 않는다. "이 앱에서는 어디에" 는 앱 MANUAL 에 적되, 원칙 번호와 이름은 여기 그대로 쓴다.

화면 문법은 소형 하드웨어 계측기(Teenage Engineering 류)에서 영감을 받았다. 특정 제품의 화면이나 로고를 가져오지 않으며, 해당 회사와는 관련이 없다.

## 01 원칙 일곱 가지

| # | 원칙 | 뜻 | Secretary–1 | Terminal–1 |
|---|---|---|---|---|
| 1 | **한 화면 = 한 모드** | 화면마다 하는 일은 하나. 핵심 값은 4개까지, 크게 | 다음 일정 카운트다운 · 노브 네 개 | 토큰 4값 · 펫 욕구 4개 |
| 2 | **색 = 조작** | 값이 어떤 키의 색이면 그 키가 그 값을 바꾼다. 인코더 네 색의 순서는 고정 | 노브 ①–④ · 번호표 색 | `F` `P` `Z` `M` · `^P` `^S` `^R` `^L` |
| 3 | **번호 붙은 구역** | 모든 구역에 두 자리 번호와 영문 대문자 이름 (`01 NEXT`). `00` 은 전체 보기. 화면이 스스로 설명한다 | `01 NEXT` · `02 TODAY` · `/도움` | 모든 칸의 `?` 가이드 · `00 overview` |
| 4 | **엔지니어링을 숨기지 않기** | 실제 상태(지연 · 주기 · 모델 · 도구 호출)를 작게 보여 준다 | 도구 호출 줄 · LED `llm` `cal` · 모델 드롭다운 | `rtt` `poll` `ev` · `sse` |
| 5 | **즉각 반응** | 누른 키에 불, 활동에 LED, 확정에 도장 | 노브 눈금 · 확정 도장 · 되돌리기 초읽기 | 키캡 점등 · 구역 LED · compose 테두리 |
| 6 | **사각 격자** | 각진 모서리, 1칸(8px) 간격, 가는 선, 앞자리 0 | 8px 점 격자 | 스펙 칸 · `01` 채널 · `00145` 카운터 |
| 7 | **캐릭터** | 앱마다 캐릭터 하나. 앱 상태를 표정 · 불빛으로 보여 준다 | 네모 화면 얼굴 · 표정 8가지 | TQ–1 펫 |

## 02 색

유채색은 **네이비 · 라임** 두 계열만 쓴다. 나머지는 무채색이다.
빨강 · 주황 · 노랑 · 보라 · 분홍은 없다. 경고는 가장 밝은 글자색 + `ERR` 칩으로 한다.

| 계열 | 이름 | hex | 쓰임 |
|---|---|---|---|
| 네이비 | `navy` | `#002341` | 본체 테두리 · 블록 바탕 · 가장 어두운 네이비 |
| | `navy1` | `#08365E` | 스펙 칸 바탕 |
| | `navy2` | `#1F507A` | 번호 배지 · 칸 이름 칩 · 버튼 · 구분선 |
| | `navy3` | `#3F77A6` | 카드 테두리 · 탭 색 |
| | `navy4` | `#75A1C7` | 인코더 ① 파랑 |
| | `navy5` | `#B8CEE0` | 옅은 네이비 글자 |
| 라임 | `lime0` | `#2C4912` | 꺼진 라임 |
| | `lime1` | `#45741B` | 눌린 라임 · 라이트 테마의 라임 글자 |
| | `lime` | `#6ABA23` | 인코더 ② · **지금 · 켜짐 · 진행 · 선택** 만 |

| | `lime4` | `#C0E79D` | 가장 옅은 라임 |
| 무채색 | `black` | `#000000` | 화면 바탕 |

| | `gray2` | `#81888D` | 보조 글자 |

- **네이비는 뼈대**(번호 배지 · 칸 이름 · 버튼 · 선), **라임은 '지금'과 '켜짐'**, **회색은 글자**, **흰색은 숫자와 경고**.
- **인코더 네 색**: ① 파랑 `#75A1C7` · ② 라임 `#6ABA23` · ③ 흰색 `#F2F2F3` · ④ 회색 `#A5AAAE`. 노브 · 키캡 · 번호표에 이 순서로만 쓴다.
- 면(surface)용 무채색(`#0B0B0B` · `#E4E6E8` 같은)은 표에 없어도 된다.
- 테마: `dark`(기본, 검정 바탕) · `light`(밝은 회색 본체) · `system`. 터미널형은 dark 하나(`Terminal-1 Black` 같은 색 테마).

검사기 기준 ([tools/works_check.py](../tools/works_check.py)): 채도(chroma)가 0.10 이상인 색은 색상각이 네이비 계열(190–230°)이나 라임 계열(75–110°) 안에 있어야 한다.

## 03 아이콘

상태 표시는 이 표의 기호만 쓴다. 모두 GNU Unifont 에서 폭 1칸이다. 폭 2칸 기호(`✓` `⚠` `★`)와 이모지는 쓰지 않는다.

| 기호 | 뜻 | 기호 | 뜻 |
|---|---|---|---|
| `●` | 켜짐 · 온라인 · 활동 LED | `○` | 꺼짐 · 오프라인 |
| `◐` | 진행 중 (돈다) | `▶` | 시작 · 선택 |
| `√` | 끝남 | `×` | 오류 · 실패 |
| `‼` | **사용자** 응답 대기 (허락 · 질문) | `⊠` | 할 일 |
| `⇣` | 압축 | `!` | 호출 |
| `▮` | LED 한 칸 = 한 단계 | `◆` | 보스 |
| `☼` | 달성 · 보너스 완료 | `⋆` | 보너스 열림 |
| `◇` | 장소 자막 | `+` | 새로 생김 |
| `›` | 하위 항목 · 넘어가기 | | |

새 기호가 필요하면 이 표에 먼저 넣는다 (폭 1칸인지 Unifont 로 확인).

## 04 글자와 숫자

- 글꼴은 **GNU Unifont 15.1.01** (8×16). 웹형은 부분집합을 내장하고 `fonts/OFL.txt` 를 함께 둔다. 터미널형은 추천 글꼴로 안내한다.
- 16px 정수배에서 가장 선명하다.
- 구역 이름 · 칩은 영문 대문자(`NEXT` · `STATUS` · `BUSY`), 설명은 한국어.
- 번호는 두 자리(`01`), 카운터는 앞자리 0(`00145`). 큰 숫자는 7세그먼트.
- 도스식 굵게: 합성 볼드 대신 1px 옆에 한 번 더 찍는다.

## 05 움직임

짧고 기계적으로 움직인다. 모든 연출은 건너뛸 수 있어야 한다.

- 켤 때 부팅: 점 격자 → 세그먼트 워드마크 → 라임 스윕
- 화면 전환: 라임 와이프
- 확정: 도장 · 되돌리기 초읽기
- 활동: 테이프 릴 · LED 깜빡임 · 미끄러지는 페이더

## 06 문서와 말투

- README 는 소개 페이지다 (OP–1 식). 뼈대는 [templates/app/README.md](templates/app/README.md).
- 존댓말, 짧은 문장. 헤드라인은 마침표로 끝나는 한 줄이다 (`다음 일정만, 크게.`).
- 소개 끝은 `전부는 아니고, 이 정도입니다:` + 대문자 사양 줄.
- 구분은 가운뎃점 ` · `, 넘어가기는 `›`.
- 이미지는 라이트 · 다크 한 쌍을 `<picture>` 로 넣고, 폭은 880(페이지) · 480–760(부품). 캡션은 `<sub>` 에 대문자 코드로 (`01 NEXT · 남은 시간 · …`).
- 한 줄 유머는 섹션 끝에 하나만 (`커피는 직접 타셔야 합니다.`).
- 이름은 화면 표기 그대로 쓴다: Secretary–1 (en dash).
- 끝에는 영감 고지문 ([RULES.md › W-12](../RULES.md#w-12-공개-저장소다)).

## 07 공용 이미지

시스템 전체를 보여 주는 이미지는 루트 [`docs/page/`](page/) 에만 둔다. 앱 README 는 `../docs/page/…` 로 가져다 쓴다.

| 파일 | 내용 | 쓰는 곳 |
|---|---|---|
| `system-{light,dark}.jpg` | 모든 앱을 나란히 | 루트 README · 앱 README 의 works 시스템 절 |
| `parts-{light,dark}.jpg` | 부품 목록 | 루트 README · 앱 README 끝 |
| `palette-{light,dark}.png` | 팔레트 | 이 파일 · 앱 README 의 색 절 |
| `colophon-{light,dark}.png` | 작업실 간판 | 루트 README · 앱 README 끝 |
| `title-*` · `certified-*` | 루트 README 전용 | 루트 README |

앱이 늘면 system · parts 이미지만 다시 찍는다. 앱 README 는 고치지 않는다.
앱마다 다른 이미지(hero · title · certified · 화면 부품)는 그 앱 폴더에 둔다.
