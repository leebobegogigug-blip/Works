# Analysis–1

손으로 다 되는 분석 도구, 옆자리에는 조수.

공정 데이터를 손으로 그리고 · 거르고 · 따집니다.
옆자리 조수 (사내 LLM) 는 제안 · 반론 · 문장으로 거듭니다.
적용은 늘 내가 누를 때만입니다.

## 상태

기획 단계 (M0) 입니다. 앱 코드는 아직 없습니다.
지금 있는 것은 기획서와 규칙 문서뿐입니다.

## 사양

전부는 아니고, 이 정도가 될 예정입니다:

- Python 3.8+ · 분석에 필요한 Python 판은 엔진 버전과 함께 M0 뒤에 적습니다
- 실행 의존성은 DuckDB 하나 · 버전은 M0 에서 하나로 고정합니다
- DuckDB 는 필수입니다 · 없으면 분석이 안 되고 `--version` · `--help` · `--check` 만 실행됩니다
- 127.0.0.1 전용
