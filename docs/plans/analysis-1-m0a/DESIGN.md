# Analysis–1 디자인

이 저장소의 화면 · 문서 규격이다 ([RULES.md › AN-09](RULES.md#an-09-디자인)).

## 01 화면 틀 — 정본은 works DESIGN.md

- 화면 틀 (구역 · 버튼 · 글자 · 노브 · 축 · 눈금 · 축 이름표 · 칩) 은 works [DESIGN.md](https://github.com/leebobegogigug-blip/Works/blob/447758f4b43ebafe7b3ec89acf7eec458ea2e27e/docs/DESIGN.md) 를 그대로 따른다 — 원칙 일곱 · 색 · 아이콘 · 글자와 숫자 · 움직임 · 문서와 말투.
- 이 문서에는 works 의 원칙 · 팔레트 값을 옮겨 적지 않는다. 원칙 번호와 이름은 works DESIGN 그대로 쓴다.
- '이 앱에서는 어디에' 는 M1 에서 `docs/MANUAL.md` 에 적는다.
- works DESIGN 이 바뀌면 [docs/UPSTREAM.md](docs/UPSTREAM.md) 의 대조 때 따라간다. 화면 틀은 따라가는 것이 기본이다 [제안].

## 02 데이터 팔레트 (AN-09)

차트의 데이터 표지 (점 · 상자 · 막대 · 선 · 밀도 칸 · die 칸 · 범례 견본 · 규격선) 만 데이터 팔레트를 쓴다. 그 밖은 모두 화면 틀이다.

### 쓰임

| 쓰임 | 층 | 정한 것 |
|---|---|---|
| 범주 (장비 · 챔버 · 제품) | 데이터 팔레트 | 12색까지 · 색각 이상 고려. 13개를 넘으면 상위 N 색 + 나머지 '그 밖' (인코더 ④ 와 다른 회색 단계) 이나 trellis 를 제안한다 [제안] |
| 연속 (밀도 · 웨이퍼 맵) | 데이터 팔레트 | 명도가 한쪽으로만 변한다 (라이트는 거꾸로). 고정 경고색을 넣지 않는다 |
| 발산 (편차 · z) | 데이터 팔레트 | 가운데 무채색 · 양쪽으로 명도가 한쪽으로만 변한다. 칸 · 범례에 부호 (+ · −) 를 붙인다 |
| 규격 밖 · 불량 · 이상점 | 고정 경고색 | 고정 경고색 + 엑스 모양 + `OOS` 칩. 빨강 계열도 된다 — 데이터 표지에서만. 맵에서는 die 칸 안에 엑스를 그려 색 없이도 구분한다 |
| 선택 · 마킹 (묶음 A) | 화면 틀 색 | lime (노브 ② · 원칙 2 '색 = 조작'). 범주 색이 켜진 그림에서는 lime 테두리 + 나머지 표지를 흐리게 |
| 묶음 B 마킹 | 데이터 팔레트 | lime 과 가장 먼 범주 색 하나를 고정한다 [제안] |
| 참조선 · 규격선 | 화면 틀 · 고정 경고색 | 참조선은 화면 틀 회색 점선 · 규격선은 고정 경고색 |
| 내보내기 (라이트) | 둘 다 | 데이터 팔레트의 라이트 판. 흰 바탕의 가는 선 · 작은 점은 lime 대신 lime1 [추정] |

### 지키는 것

- 고정 경고색은 범주 · 연속 · 발산 단계의 한 칸으로 쓰지 않는다 — '가장 높은 die' 와 '불량 die' 가 같은 색이 되지 않게. 한 그림에 단계와 경고 표지 (규격선 · 엑스) 를 함께 쓰는 것은 된다.
- 데이터 팔레트에는 lime 과 헷갈리는 색을 넣지 않는다 — 마킹한 die 와 범주 색이 섞이지 않게. 범주 단계에는 나머지 인코더 세 색과 헷갈리는 색도 넣지 않는다 [제안].
- 연속 · 발산은 색상각을 크게 돌리지 않고 명도로 만든다. lime 으로 이어지는 보간을 만들지 않는다.
- 색은 계산하지 않는다. 단계를 `ui.html` 의 CSS 토큰으로 미리 두고, `build.py` 가 그 표를 `analysis1_assets.py` 로 내보내고, 서버 그리기도 그 표만 쓴다. `hsl(` · 색 보간 코드는 쓰지 않는다.
- 데이터 팔레트 토큰은 이름 머리를 화면 틀 토큰과 달리해 따로 묶는다 [제안] — 화면 틀 색 검사가 데이터 팔레트를 위반으로 읽지 않고, 화면 틀 규칙 (구역 · 버튼 · 칩) 이 데이터 팔레트 토큰을 쓰면 시험이 실패하게. 머리 이름은 값과 함께 정한다.
- 경계 [제안]: 그림 영역 안 (점 · 선 · 막대 · 칸 · 웨이퍼 die · 범례 견본 · 규격선) 은 데이터 팔레트, 그 밖 (구역 · 칩 · 축 이름표 · 버튼 · 06 TABLE · 웨이퍼 얼굴) 은 works 팔레트다. 06 TABLE 의 규격 밖 행은 경고색이 아니라 `OOS` 칩이다.
- 직접 이름표 · 스포트라이트 (사용자가 켬) · trellis · 모양은 색과 함께 쓰는 보조 수단으로 남는다.

### 값과 검사 — 아직 비어 있음

- 값은 지금 적지 않는다. 값과 검사는 M1-b1 앞에 채운다 — 연속 · 범주 · 고정 경고색은 M1-b1 (밀도 · 웨이퍼 맵 v0 · 장비별 색 · 규격선) 앞, 발산은 처음 쓰는 판 앞.
- 채울 때 함께 정할 것: 다크 · 라이트 두 판의 토큰 표 · 범주 12색이 서로 · lime 과 구분되는 기준 · 색각 이상에서 구분되는 기준 · 연속 · 발산의 명도가 한쪽으로만 변하는지의 기준 · '그 밖' 회색 단계.
- 지키는 곳: 색 시험 (M1-b1) · `tests/test_rules.py` (화면 틀 색) — [RULES.md › AN-09](RULES.md#an-09-디자인).
